# Therazo website

Next.js site for therazo.co. Brand facts and claims rules live in `CLAUDE.md`;
current status and open items in `PROGRESS.md`.

```bash
npm run dev     # localhost:3000
npm run build   # production build
npm run lint    # ESLint
npm run track   # face tracking for the hero video (see below)
```

## Hero video

The customer-portal hero (`/customers`) plays `hero-play-once.mp4` once,
forwards, muted and inline, then holds on the final frame. It never restarts
by itself; if the hero scrolls out of view and back in, it replays once from
the start. Visitors with reduced motion see the poster only. The video is
clean footage; the scanner graphics are drawn on top in code
(`components/HeroScanner.tsx`) and locked to the face using landmarks tracked
offline.

`HeroScanner` also has `mode="loop"` (the native loop attribute, forwards
only) for a seamless loop clip, should one be supplied. Nothing plays in
reverse.

| File | What it is |
|---|---|
| `public/videos/hero-play-once.mp4` | 8 s clip, plays once |
| `public/videos/hero-poster.webp` | first frame of the clip (also the reduced-motion image) |
| `public/data/hero-play-once.landmarks.json` | per-frame face anchors, generated by `npm run track` |
| `lib/heroVideo.ts` | clip path and poster |
| `lib/heroScannerTimeline.ts` | when each overlay element shows |
| `content/heroLabels.ts` | scan label wording |

### Face tracking setup

`scripts/track_face.py` uses MediaPipe Face Landmarker and OpenCV. It needs
Python 3.9+ and, on Linux, the system EGL library (`libegl1`).

```bash
pip install mediapipe opencv-python
npm run track
```

The first run downloads the Face Landmarker model to `scripts/models/`
(git-ignored). Commit the regenerated JSON files.

### Swapping in new footage

1. Drop the new clip into `public/videos/` using the same file name
   (`hero-play-once.mp4`).
2. Regenerate the poster from its first frame:
   ```bash
   ffmpeg -i public/videos/hero-play-once.mp4 -vf "select=eq(n\,0)" -frames:v 1 -c:v libwebp -quality 82 public/videos/hero-poster.webp
   ```
3. Run `npm run track`.
4. Rebuild (`npm run build`), open `/customers?debug=1` and check that the red
   anchor dots sit on the face at 390, 768 and 1440 px wide.
5. Retime `lib/heroScannerTimeline.ts` if the head movement has changed.
